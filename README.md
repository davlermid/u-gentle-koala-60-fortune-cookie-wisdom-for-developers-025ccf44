Entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/competitions/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on [make.fun](https://make.fun).

`main.ts` (Node 22, stdlib-only, no network) writes one original fortune-cookie line for a software developer — 120 characters or fewer — to `/output/entry.txt`:

> Your future self will read this code at 2 a.m.; write it like a letter to a friend, not a riddle.

Run it with `node main.ts`. Prize pool $2, split over the top two entries; deadline 27 Nov 2026.
